## Full description (2038 / 4000)

```
Tik om te flappen. Stuiter van muur naar muur. Raak de spikes niet.

Flapjaw is een snel arcadespel dat je met één duim speelt. Elke tik is een flap, elke muur stuurt je terug naar de andere kant, en elke kamer bedenkt iets nieuws om je tegen te houden.

KAMERS DIE STEEDS VERANDEREN
Elke run brengt je van kamer naar kamer: zagen, lava, lasers, slingers, pletters, wind, grotten, bewegende blokken en bazenkamers. Hoe verder je komt, hoe lastiger het wordt. Geen twee runs zijn hetzelfde.

DAILY RUN
Eén kaart per dag, voor iedereen ter wereld dezelfde. Je krijgt drie pogingen; je beste telt op het Daily Run-bord. De top 10 wint diamanten als de dag voorbij is.

BATTLE
Daag een vriend of een willekeurige speler uit voor een Battle. Elke ronde is een nieuwe kaart: één van jullie speelt hem eerst, de ander speelt dezelfde kaart met die run als doorzichtige tegenstander ernaast. De hoogste score wint de ronde, en wie het eerst zes rondes wint, wint de Battle. Speel je beurt wanneer je wilt; de game laat weten wanneer je aan de beurt bent.

DUEL
Speel live. Jij en je tegenstander vliegen tegelijk over dezelfde kaart en zien elkaars vogel meteen. Best of three. Nodig een vriend uit met een code, of vind binnen een paar seconden een tegenstander.

EERLIJKE SCORES
Elke run op de borden wordt gecontroleerd door hem op onze server opnieuw af te spelen, dus de topscores zijn echt. Bekijk de replays van de beste runs en zie hoe ze het deden.

ZIE ERUIT ZOALS JIJ WILT
Speel flyers, werelden, sporen, portalen, muziek, crash-effecten en bordplaatjes vrij met munten die je verdient door te spelen. Alles wat je kunt kopen verandert alleen hoe de game eruitziet. Elke flyer is even groot en beweegt hetzelfde: nooit pay-to-win.

GRATIS TE SPELEN
Flapjaw is gratis. Je krijgt elke dag drie gratis revives; daarna kun je een vrijwillige advertentie bekijken voor nog een kans. Advertenties komen alleen als jij erom vraagt.

Botspelers in Battles en Duels hebben altijd het label BOT.

Vragen of ideeën? Mail ons op {{CONTACT_EMAIL}}.
```

## Notes

- Mode names (Daily Run, Battle, Duel, BOT) stay English: that is what the game shows. If the
  game gets a Dutch translation later, match these to it.
- "Spikes" stays English on purpose (it is the game's word, and Dutch players use it);
  "pinnen" or "stekels" are the Dutch options.
